# Документация

## Инструменты агента

| Инструмент | Что делает |
|:---|:---|
| `ask_questions` | Задаёт пользователю уточняющие вопросы |
| `web_search` | Ищет информацию в интернете по запросу |
| `calculator` | Считает арифметическое выражение |

## Как добавить инструмент

Объявите функцию и оберните её декоратором `@tool(name, description)` — она попадёт в реестр `TOOLS`.
